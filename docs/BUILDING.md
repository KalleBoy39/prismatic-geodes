# Building from source

Players don't need this. Ready-made files are on the [Releases](https://github.com/KalleBoy39/prismatic-geodes/releases)
page.

## Requirements
- **JDK 25.** Any full JDK 25 works for the mods. The locator build also needs `jlink` and `jpackage`, so use a
  complete JDK such as [Eclipse Temurin 25](https://adoptium.net/). Point `JAVA_HOME` at it.
- Internet access on the first build (Gradle, Minecraft and Fabric downloads).
- Windows for the locator. The two mods build on any OS.

Everything else (Gradle 9.7.1, Fabric Loom 1.18.4, Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.162.0+26.3) is
downloaded by the Gradle wrapper and the build scripts.

## Prismatic Geodes (main mod)
```
gradlew build
```
- Output: `build/libs/prismatic-geodes-1.0.0+26.3.jar`
- `build` also runs the 18 server game tests (a throwaway test server; the build accepts the Minecraft EULA for that
  test server only).
- `gradlew runClientGameTest` starts a real client in a throwaway world and saves screenshots under
  `build/run/clientGameTest/screenshots`.
- `gradlew runClient` starts a development client in `run/client` (never your normal `.minecraft`).

## Prismatic Geodes: Mini Blocks
Build the main mod first. The addon's tests load it from `build/libs` of the main project.
```
cd compat/miniblocks
gradlew build
```
- Output: `compat/miniblocks/build/libs/prismatic-geodes-miniblocks-1.0.0+26.3.jar`
- 5 server game tests; `gradlew runClientGameTest` for screenshots.
- All data and textures in `src/main/resources` are generated by `tools/generate.py` and committed. Regenerating
  them needs the Vanilla Tweaks Mini Amethyst Block skin as a template, which is **not** in this repository (it is
  Vanilla Tweaks artwork). See [compat/miniblocks/tools/templates/README.md](../compat/miniblocks/tools/templates/README.md).

## Prismatic Geode Locator (Windows)
Build the main mod first. The locator bundles that jar.
```
powershell -ExecutionPolicy Bypass -File tools\geode_locator\build-public.ps1 -Jdk "C:\path\to\jdk-25" -Out "C:\some\output\folder"
```
- Output: the app folder `Prismatic Geode Locator\` and `Prismatic-Geode-Locator-1.0.0-windows-x64.zip`.
- On the first run the script downloads the Minecraft 26.3 server (Mojang), Fabric Loader and Fabric API (FabricMC)
  into `tools/geode_locator/runtime/build-deps`, checked against pinned hashes. They are only used to compile and are
  never put into the output.
- The script fails if the privacy audit finds developer paths or private files in the output.

Details: [tools/geode_locator/README.md](../tools/geode_locator/README.md).

## Versions
`<mod version>+<Minecraft version>`, for example `1.0.0+26.3`. MAJOR for anything that breaks existing worlds
(removed or renamed blocks/items), MINOR for new content, PATCH for fixes. The locator has its own version and is
re-released whenever the mod's world generation changes, because it bundles the mod jar it predicts.
