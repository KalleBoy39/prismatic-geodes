# Prismatic Geodes 1.0.0 (DRAFT, not published)

First public release, for **Minecraft Java Edition 26.3** with **Fabric**.

Prismatic Geodes adds amethyst geodes in all 16 Minecraft dye colours while keeping vanilla-like generation and
mechanics.

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

## Downloads

| File | What it is | Needed? |
|---|---|---|
| `prismatic-geodes-1.0.0+26.3.jar` | **Prismatic Geodes**, the mod (client and server) | yes |
| `prismatic-geodes-miniblocks-1.0.0+26.3.jar` | **Prismatic Geodes: Mini Blocks**, a separate addon with decorative mini blocks | optional |
| `Prismatic-Geode-Locator-1.0.0-windows-x64.zip` | **Prismatic Geode Locator**, a separate seed map program for Windows (Java included) | optional |

You also need **Fabric Loader 0.19.5+** and **Fabric API** for 26.3 (tested with 0.162.0+26.3).
How to install: [INSTALLATION.md](https://github.com/KalleBoy39/prismatic-geodes/blob/main/docs/INSTALLATION.md).

## What's in it

**Prismatic Geodes 1.0.0+26.3**
- Geodes generate in all 16 dye colours, one colour per geode, each colour equally likely. Purple is vanilla amethyst.
- Vanilla rarity, height range and placement. Only newly generated chunks are affected.
- 15 new amethyst families: block, budding block, small/medium/large bud, cluster, shard. Budding blocks grow buds of
  their own colour at vanilla speed.
- Vanilla drops, Fortune and Silk Touch. 4 shards → block of the same colour. Spyglass, tinted glass and calibrated
  sculk sensor accept shards of any colour.
- Every shard colour is an armour trim material.

**Prismatic Geodes: Mini Blocks 1.0.0+26.3** (separate, optional addon)
- Mini blocks for the 15 coloured amethyst blocks: 1 block → 8 in a stonecutter. Made to fit next to Vanilla Tweaks
  Mini Blocks; head textures recoloured from its Mini Amethyst Block. No duplicate purple. Requires Prismatic Geodes.

**Prismatic Geode Locator 1.0.0** (separate, optional tool; Windows 10/11, 64-bit)
- Terrain map from your seed, crystal markers in all 16 colours, exact coordinates, copy buttons and `/tp` command.
- **Verify visible area** confirms which geodes really formed by building the area in a hidden local test world.
- First start: accept the Minecraft EULA, then it downloads the official Minecraft 26.3 server (Mojang) and Fabric
  files, checked against fixed checksums. Windows may show a SmartScreen warning (the program is not signed): click
  *More info* → *Run anyway*.

## Before you add it to an existing world
Back up your world. Once coloured blocks exist, the world needs the mod; removing it turns coloured blocks into air.
